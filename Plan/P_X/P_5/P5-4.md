**练习 2 手工 compaction 样例（供对答案）**
- 输入 log 顺序：

```text
PUT a=1
PUT b=2
PUT a=3
DELETE b
PUT c=4
```

- compaction 后有效 KV：`a=3, c=4`。
- `b` 的 PUT 与 DELETE 都可丢弃。
- 索引应只指向 a 和 c 的最新 offset。

- 若你的合并结果里还有 `b=2`，说明 tombstone 规则没吃透。

**页式 vs 日志结构：选型速查**
- 选页式 heap（bustub 主线）当：
  - 单行点查/更新多
  - 需要 RID + B+ 树稳定接口
  - 教学链要接 WAL redo page

- 选 append-only / LSM 当：
  - 写密集、可 batch
  - 能容忍读放大和后台 compaction
  - KV 或时序 append 负载

- 选列存（P6）当：
  - OLAP 少列扫描
  - 压缩和向量化收益大

- 三者不是互斥；现代系统常混合，但 bustub 教学栈按 P3→P4→索引→WAL 顺序最稳。
