```text

```

**Gradescope / 项目常见失败模式**
- `Insert pass, Delete fail`：merge 未修 next 或父 key stale——专测 Delete 边界。
- `Iterator wrong order`：split 后 next 断链——每次 Insert 后跑 CheckLeafChain。
- `Root height wrong`：root 只剩一个 child 未降级——构造 height=2 再删光一侧。
- `Concurrent fail`（P10）：先确认单线程全绿，再查 latch，不要同时改 Insert 和 crabbing。

**Delete 专项验收（建议单独做）**
- 很多人在 Insert 过关后卡在 Delete。建议单独开一轮验收：
- 仅 Insert 1..50，Delete 25——树仍合法，Get(1) 和 Get(50) 正确。
- Insert 1..50，Delete 1..50 升序——最终空树或空叶，再 Insert 可继续。
- Insert 1..50，Delete 1..50 降序——测 merge 链。
- 每轮 Delete 后调用 CheckLeafChain。
