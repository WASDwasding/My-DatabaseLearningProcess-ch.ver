**Gradescope / 并发项目常见失败模式**
- `Deadlock`：兄弟页交叉 latch——固定 page_id 递增顺序。
- `Self deadlock`：同一 page FetchPageWrite 两次——用 write_set_ 检查是否已持有。
- `UAF / segfault`：Guard move 后使用旧指针——ASAN + 禁止存 AsMut  raw pointer。
- `Pass locally, fail CI`：缺 stress；加 8 线程各 Insert 1..10000 unique key，最后 Iterator 计数。

**Buffer Pool 与 Latch 的完整生命周期（收口）**

```text
FetchPageWrite(id):
  1. 在 page table 找 frame；若无则 evict + 读盘
  2. pin_count++
  3. acquire X latch on frame
  4. 返回 WritePageGuard（持有 latch + pin）

~WritePageGuard():
  1. release X latch
  2. pin_count--
  3. Unpin（可能触发 evict 候选）
```

- 常见错误：手动 Fetch 后不 Unpin，buffer pool 耗尽；或 Unpin 后仍用 page 指针写数据。
- P10 验收时，除 B+Tree 外，应能口述 Guard 析构的上述顺序。
