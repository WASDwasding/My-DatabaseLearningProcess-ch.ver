**常见卡点**

**卡点 1：把 merge 当成“再 sort 一遍”**
- merge 前提是 run 已有序；复杂度是 O(n log k)，不是 O(n log n) 全表重排。

**卡点 2：hash agg 输出顺序当语义**
- hash table 遍历顺序无序；除非 SQL 要求 ORDER BY，否则结果集无序是正常的。

**卡点 3：GROUP BY 无行 vs 全局 agg**
- `SELECT COUNT(*) FROM empty` → 1 行；`SELECT dept, COUNT(*) ... GROUP BY dept` on empty → 0 行。

**卡点 4：spill 当不存在**
- 教学代码可能不 spill；面试和生产问“内存不够怎么办”必须答 partition/spill。

**卡点 5：忽略临时文件生命周期**
- 查询 abort 或异常时 temp run 必须删除，否则磁盘泄漏。

**卡点 6：top-N comparator 与 ORDER BY 不一致**
- DESC/ASC、NULLS FIRST/LAST 错一位，LIMIT 边界全错。
