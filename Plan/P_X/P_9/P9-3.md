**倒排索引：边界与陷阱**

**边界**
- 空词典、单 term 单 doc、超长 posting、空 posting 交集。
- 同 doc 重复 term（tf 累加 vs 重复 posting 项）。
- 删除 doc 后 posting 留空洞——需 compaction 或 tombstone。

**陷阱**
- 分词不一致：索引用 Porter stemmer，查询不用 -> 查不到。
- 大小写：必须统一 lower case。
- 停用词 `"the"` 若进索引，list 巨大无判别力。

**最小实现**

**对应 Code 目录**
- 这一段如果要动手实现，代码统一放在 `Code/p9_aux_indexes/`。
- 这一课在 `Code/` 里的主题是：`倒排、Bloom、跳表、向量索引的 toy 实验`。
- 建议起手顺序：先选其中一个结构做教学版最小实现，不必全做。


```cpp
using Posting = std::vector<int>;  // doc_id
std::unordered_map<std::string, Posting> index;

void IndexDoc(int doc_id, const std::string &text) {
  for (auto &term : Tokenize(text)) {
    index[term].push_back(doc_id);
  }
}

std::vector<int> QueryAnd(const std::string &t1, const std::string &t2) {
  auto &a = index[t1], &b = index[t2];
  std::vector<int> out;
  size_t i = 0, j = 0;
  while (i < a.size() && j < b.size()) {
    if (a[i] == b[j]) { out.push_back(a[i]); i++; j++; }
    else if (a[i] < b[j]) i++;
    else j++;
  }
  return out;
}
```

**调试**
- 索引 3 篇固定短文，手算 AND/OR，与程序对比。
- 强制 posting 排序：`std::sort` 后去重 doc_id。

**bustub 扩展思路**
- 离线工具：读 CSV 文本列，写倒排文件；查询走独立进程，不耦合 executor。
- 或在 TableScan 上叠一层“mock IR”实验，理解即可。

**布隆过滤器：边界与陷阱**

**边界**
- n=0 全 false；n 远超设计容量；m=0 非法。
- 同一 key 重复 Insert（幂等，位已是 1）。
- Query 从未 Insert 的 key（应 false）。

**陷阱**
- k 太大：每位被置 1 次数多，假阳性升，且 CPU 增。
- k 太小：区分度不够，假阳性升。
- 用单一 hash 拆 k 份代替 k 个独立 hash（弱依赖 double hashing 可接受，但要一致）。

**最小实现 + 实验**

```cpp
// 插入 n 个 key，对 10n 个未插入 key 测 false positive rate
void MeasureFP(int m, int k, int n) {
  BloomFilter bf(m, k);
  std::set<uint64_t> inserted;
  for (int i = 0; i < n; i++) {
    bf.Insert(i);
    inserted.insert(i);
  }
  int fp = 0, trials = n * 10;
  for (uint64_t x = n; x < n + trials; x++) {
    if (bf.MaybeContains(x)) fp++;
  }
  printf("empirical fp rate ≈ %.4f\n", (double)fp / trials);
}
```

**调试**
- 画曲线：x 轴 n/m，y 轴假阳性率，对比公式预测。
- 验证**无漏报**：Insert 过的 key 必须 MaybeContains=true。

**bustub 扩展思路**
- 在 SeqScan 前维护 page-level Bloom：Insert tuple 时把 page_id 或 rid 加入 Bloom；点查 miss 可 skip page（demo 级）。

**跳表：边界与陷阱**

**边界**
- 空表 Find/Insert/Delete。
- 重复 Insert 同一 key（更新或拒绝）。
- Delete 最小/最大 key。
- RandomLevel 总是 0 -> 退化成链表，仍正确但慢。

**陷阱**
- 插入层高 > 当前 max level 未提升 head level。
- Delete 未正确 unlink 各层 -> 内存泄漏或断链。
- concurrent 无锁版：ABA、指针撕裂——P10 前只做单线程。

**最小实现骨架**

```cpp
struct Node {
  int key;
  std::vector<Node*> forward;
};

class SkipList {
  Node* head;
  int max_level;
  bool Search(int key);
  void Insert(int key);
  void Remove(int key);
};
```

**调试**
- Insert 1..100，Search 全命中。
- 与 `std::set` 对拍随机 Insert/Remove。
- 打印各层链表，目视有序。

**bustub 扩展**
- 替换某个 MemTable 实验模块为 SkipList，flush 时中序遍历写 SSTable——理解 LSM 写路径。

**向量 ANN：边界与陷阱**

**边界**
- N=1、K=1、K>N。
- 全相同向量（距离全 0）。
- 高维随机向量（最近邻不稳定，recall 评估需固定 seed）。

**陷阱**
- 未 normalize 却用内积当相似度。
- IVF 只查 1 个 centroid，recall 极低。
- 把训练聚类和查询数据分布混用错误。

**最小实验（暴力 baseline + IVF sketch）**

```cpp
// 暴力 top-K
vector<int> BruteTopK(const vector<float>& q,
  const vector<vector<float>>& data, int K) {
  priority_queue<pair<float,int>> heap;
  for (int i = 0; i < data.size(); i++) {
    float d = L2(q, data[i]);
    heap.push({d, i});
    if (heap.size() > K) heap.pop();
  }
  // ...
}

// IVF: 只扫描最近 2 个 cluster 的向量，算 recall@K vs brute
```

**调试**
- 固定 1000 个 2D 向量，可视化真 top-5 vs ANN top-5。
- 报告 recall@K 随 `nprobe`（扫描 cluster 数）变化。

**bustub 扩展**
- 不必集成；独立 Python/C++ notebook 即可。重点是理解 trade-off，不是工程完工。

**倒排 intersection 双指针模板（背诵级）**

```cpp
while (i < a.size() && j < b.size()) {
  if (a[i] == b[j]) { out.push_back(a[i]); i++; j++; }
  else if (a[i] < b[j]) i++;
  else j++;

```

- AND 查询核心；P9 实验 1 应与此模板结果一致。

**Bloom 无漏报验证伪代码**

```cpp
for (auto k : inserted_keys)
  assert(bf.MaybeContains(k));  // 必须全 true
```

- 若出现 false，说明 bitmap 或 hash 实现有 bug，而非“正常误报”。

---

**常见卡点**
- `倒排只会建不会 intersection` -> 双指针模板背熟。
- `Bloom 误报当漏报` -> 重新读 P9-2 无漏报定义。
- `跳表插入忘提升 head level` -> Insert 后 assert level0 有序。
- `ANN 不报告 recall` -> 任何 ANN 实验必须对比 brute baseline。
